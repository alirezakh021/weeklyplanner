# برنامه‌ریز هفتگی

اپلیکیشن شخصی برنامه‌ریزی روزانه — روزهای ثابت هفته (هر تعدادی که بخوای) + روزهای متغیر،
با تیک زدن آیتم‌ها، استریک، برچسب، اولویت، زمان و مدت تخمینی، یادداشت روزانه، آیتم‌های
تکرارشونده با فاصله دلخواه، جستجو، تاریخچه، نمودار روند، مقایسه‌ی هفته‌ها، بینش روزهای هفته،
حالت تمرکز، پشتیبان‌گیری، حالت تاریک و افزودن سریع.

## رفع باگ مهم (نسخه‌ی فعلی)

قبلاً وقتی برنامه‌ی ثابت یک روز رو *بعد از بار اول* ویرایش می‌کردی (مثلاً یک آیتم جدید
اضافه می‌کردی یا متن یکی رو عوض می‌کردی)، این تغییرات روی روزهایی که سرور از قبل
تولید کرده بود اثر نمی‌کرد. الان هر آیتم قالب و هر آیتم تکرارشونده یک شناسه‌ی ثابت داره؛
هر بار که تنظیمات رو ذخیره می‌کنی، سرور همه‌ی روزهای *امروز به بعد* رو با قالب جدید
همگام می‌کنه (آیتم جدید اضافه می‌شه، ویرایش‌شده به‌روز می‌شه، حذف‌شده پاک می‌شه) — بدون
اینکه به تیک‌خورده‌ها یا آیتم‌های دستی‌ای که خودت به یک روز خاص اضافه کردی دست بزنه.
روزهای گذشته هیچ‌وقت دست‌کاری نمی‌شن.

## اجرا روی VPS (یا لوکال برای تست)

نیاز: Node.js نسخه ۱۶ به بالا.

```bash
cd weekly-planner
npm install
npm start
```

پیش‌فرض روی پورت `3210`. برای تغییر پورت: `PORT=8080 npm start`

### اجرای دائمی با pm2

```bash
npm install -g pm2
pm2 start server.js --name planner
pm2 save
pm2 startup
```

### پشت Nginx (اختیاری)

```nginx
server {
    listen 80;
    server_name planner.example.com;
    location / {
        proxy_pass http://127.0.0.1:3210;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## راهنمای فیچرهای جدید

- **روزهای ثابت انعطاف‌پذیر**: هر تعداد روزی که بخوای (نه لزوماً ۳ تا) رو در تنظیمات به‌عنوان ثابت انتخاب کن.
- **برچسب رنگی و اولویت**: روی هر آیتم یک دایره‌ی رنگی (برچسب: کار/سلامتی/شخصی/درس) و یک ستاره (اولویت) هست.
- **ساعت و مدت تخمینی**: هر آیتم می‌تونه ساعت و مدت تقریبی (به دقیقه) داشته باشه؛ مجموع زمان باقی‌مونده‌ی روز بالای لیست نشون داده می‌شه.
- **آیتم‌های تکرارشونده**: در تنظیمات، بخش «آیتم‌های تکرارشونده» — مستقل از روزهای ثابت، با فاصله‌ی دلخواه (مثلاً هر ۱۴ روز).
- **کپی الگوی هفته**: در تنظیمات، آیتم‌های روزهای متغیرِ هفته‌ی جاری رو به چند هفته‌ی بعد کپی کن.
- **جستجو**: آیکون ذره‌بین بالا — جستجو در متن همه‌ی آیتم‌های ثبت‌شده.
- **آمار**: آیکون نمودار بالا — شامل تقویم ۵ هفته‌ای، روند ۳۰ روزه، مقایسه‌ی این هفته با هفته‌ی قبل، میانگین تکمیل به تفکیک روز هفته، و تاریخچه‌ی قابل فیلتر.
- **حالت تمرکز**: دکمه‌ی «شروع حالت تمرکز» در پایین لیست هر روز — آیتم‌های باقی‌مونده رو یکی‌یکی تمام‌صفحه نشون می‌ده.
- **افزودن سریع**: دکمه‌ی شناور گرد پایین صفحه — بدون اسکرول به پایین، مورد جدید به روز جاری اضافه می‌کنه.
- **فیدبک لمسی/صوتی**: با تیک زدن هر آیتم، یک ویبره‌ی کوتاه (اگر گوشی پشتیبانی کنه) و یک صدای ملایم پخش می‌شه.
- **پشتیبان‌گیری**: در تنظیمات، «خروجی گرفتن» یک فایل JSON کامل دانلود می‌کنه؛ «وارد کردن فایل» همون فایل رو برمی‌گردونه.
- **حالت تاریک**: آیکون خورشید/ماه بالای صفحه؛ انتخابت توی مرورگر همون گوشی ذخیره می‌مونه.
- **پس‌زمینه‌ی پویا**: دو لکه‌ی رنگی محو که هنگام اسکرول با سرعت‌های متفاوت حرکت می‌کنن (افکت parallax ملایم).

### نصب به‌عنوان اپ (PWA) — توضیح شماره ۷

بعد از بالا آوردن روی VPS (با HTTPS، چون مرورگرها PWA رو فقط روی HTTPS یا localhost نصب می‌کنن)،
وقتی از گوشی وارد آدرس بشی، مرورگر (کروم/سافاری) گزینه‌ی «Add to Home Screen» یا «نصب اپ» رو نشون
می‌ده. با این کار یک آیکون روی صفحه‌ی اصلی گوشی می‌شینه و اپ بدون نوار آدرس مرورگر باز می‌شه —
دقیقاً حس یک اپ واقعی.

**نکته‌ی مهم:** این فقط *پوسته‌ی* اپ (HTML/CSS/JS) رو برای بارگذاری سریع‌تر کش می‌کنه، نه داده‌هات را.
چون داده‌ها روی سرور خودت ذخیره می‌شن (نه روی خود گوشی)، برای دیدن یا ذخیره‌ی برنامه‌ی واقعی هنوز
به اتصال اینترنت به سرورت نیاز داری. یعنی PWA اینجا یعنی «شبیه اپ نصب‌شده»، نه «کاملاً آفلاین».

## نکات مهم

- **بدون احراز هویت:** این اپ لاگین نداره. اگه روی آی‌پی عمومی بالا میاریش، پشت فایروال/VPN
  بذارش یا یک Basic Auth روی Nginx اضافه کن.
- **یادآوری‌ها:** فقط وقتی تب مرورگر باز باشه کار می‌کنن (چک هر ۲۰ ثانیه). یادآوری واقعی در
  پس‌زمینه به Service Worker + Push Server نیاز داره که در این نسخه پیاده نشده.
- فونت‌ها (Vazirmatn و Lalezar) از Google Fonts لود می‌شن؛ برای آفلاین کامل، فایل‌های فونت رو
  دانلود و لوکال سرو کن.

## داده‌ها کجا ذخیره می‌شن؟

در فایل `data/db.json` (خودکار ساخته می‌شه). به‌طور دوره‌ای از این فایل بک‌آپ بگیر — یا از
دکمه‌ی «خروجی گرفتن» داخل خود اپ استفاده کن.
